# 长图交付

把培训、项目、活动的图文内容编排成一张 **1080 像素宽的交付长图**，在浏览器里编辑、实时预览，导出 PNG 长图或按比例切图。

单个 `index.html` 文件，不需要安装，不需要服务器。所有图片和文字都只在你自己的浏览器里处理，不会上传。

## 在线使用

线上地址：http://121.5.21.95:8080/

也可以直接下载 `index.html`，双击用 Chrome / Edge / Safari 打开，离线可用。

## 功能

- **一键导入**：把 AI 写好的文字稿（DeepSeek、Kimi、豆包等）或 Word（.docx，含照片）一次导入成篇章；工具内可复制提示词、下载 Word 模板
- **8 套版式**，分 3 组：现代简约（素白、墨夜、网格）、稳重政企（松绿、朱印、靛青）、科技质感（玻璃、蓝图）
- **17 种背景底纹**，分三组：传统纹样（青海波、远山、回纹框、祥云）、现代几何（网点球、几何块面、斜向网点、同心圆环、包豪斯、斜纹带、像素方块、加号阵列、彩虹弧、孟菲斯）、光影科技（流光、光斑、节点网络）；可调强度，可选跟随主题 / 金色 / 标题块色 / 自定义颜色
- **图文篇章**：每个篇章是独立的圆角卡片和标题块，照片可 1 / 2 / 3 列排版、拖拽上传、粘贴、调整顺序
- **正文局部格式**：选中几个字单独加粗、斜体、下划线或用强调色突出
- **字体**：标题和正文可分别选黑体或内置的思源宋体
- **Logo**：内置邮储银行、中国邮政、中原银行，也可上传自己的；可缩放、左右移动，深色主题自动反白
- **标题栏**：每行单独设字号、粗细、字体和颜色，默认跟随主题；页头高度自动贴合内容
- **导出**：整张 PNG 长图，或按 1:1、4:5（小红书）、9:16 自动切图并打包成 ZIP
- **工程文件**：保存为 `.json`，随时导入继续编辑；兼容旧版 `.oneimg`
- **撤销 / 重做**（Ctrl / ⌘ + Z），编辑区与预览区宽度可拖动调整，各模块可折叠

## 条幅预览

顶栏「长图交付 / 条幅预览」滑块切换。用于培训条幅、背景布给客户确认，改完直接出印刷文件，不必再来回找后台设计。

- **上预览、下编辑**：按真实比例显示，标注宽高（米）；可看当前条幅或全部条幅，预览区高度可上下拖动
- **多条条幅**：新增、复制、删除；每条单独设文字（回车换行）、尺寸、材质、数量
- **默认红底白字**，底色 / 字色有常用色和自定义；黑体、宋体、楷体，可加粗、细边框
- **字号**：直接填实际字高（厘米），或留空按条幅高度自动；字距、两端留白可调，放不下时会提示并自动缩小
- **尺寸预设**：横幅、背景布 / 桁架、竖幅（竖幅自动竖排）
- **Logo**：内置邮储银行、中国邮政、中原银行，或上传 / 粘贴图片；横幅放在文字左侧，背景布放在文字上方；大小可调并显示实际宽高（厘米），位置可选上 / 中 / 下（背景布、竖幅为顶部 / 文字上方 / 文字下方）
- **导出**：
  - 确认单图片（PNG）：只含所有条幅的效果、尺寸、颜色、字体、字高和签字栏，直接发客户
  - 印刷 PDF：每条一页，页面就是实际尺寸
  - 印刷 JPG：按实际尺寸出图并写入 DPI，文件名含尺寸、材质、数量；过长的条幅会自动降低分辨率以免浏览器画不出来
  - 打印单 CSV：Excel 打开，含尺寸、材质、数量、颜色（含参考 CMYK）、字高和对应文件名
  - 一键导出：以上全部打包成一个 ZIP

## 发布

此仓库的 `main` 分支是网站的发布来源。修改根目录的 `index.html` 并推送到 `main` 后，云服务器通常会在下一分钟自动拉取并发布新版本，无需手动登录服务器。

服务器上的网站运行在独立的 `zhibo-site` 服务和 8080 端口，不影响原有 80 端口服务。发布脚本位于 `/usr/local/sbin/deploy-zhibo-site`，定时配置位于 `/etc/cron.d/zhibo-site`，日志位于 `/var/log/zhibo-deploy.log`。

## 说明

- 宋体通过 Google Fonts 按需加载用到的字；离线或无法访问时自动改用电脑自带的宋体。
- 浏览器画布的高度上限是 16384 像素，内容过长时请减少篇章或照片，或改用切图导出。
- 条幅草稿与长图草稿分开保存。
- 草稿自动保存在当前浏览器；换电脑或清理浏览器数据前，请先「保存工程」。
